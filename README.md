# Bruins Site

A Boston Bruins analytics fan site — companion project to the Patriots site
("Foxboro Files") and Red Sox site ("The Fenway Almanac"). Not yet built beyond
scaffolding; see [PROJECT-PLAN.md](./PROJECT-PLAN.md) for the architecture
decision and starting points.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
